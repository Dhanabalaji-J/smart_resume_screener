# Smart Resume Screener

Smart Resume Screener is an intelligence tool for the hiring process that looks at resumes and job descriptions to check if people are a good fit what skills they have, what experience they bring and what education they have.

The system uses Google Gemini AI to create match scores find out what skills are missing give advice that helps with the application tracking system and has RAY, an intelligence helper that focuses on making resumes better and finding the right jobs.

---

## Features

- Upload resumes in PDF format

- Automatically read information from the resume

- Type in a job description

- Check the resume against the job needs using Gemini AI

- Create a match score from 1 to 10

- Find the skills that match

- Find the skills that are missing

- Look at how experience fits

- Look at how well education fits

- Create a reason why a candidate is suitable using AI

- Dashboard for screening candidates

- Analytics for candidates

- Keep candidate analysis in MongoDB

- RAY AI helper for resumes

- Suggestions for improving the resume for the application tracking system

- Advice on how to make the resume better

- Show candidates, in the current session

- Interface that works on all devices
